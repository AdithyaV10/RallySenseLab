## Sizing and remaining external acceptance

Five runtime caps total **2,281,701,376 bytes (2.125 GiB)**. In the latest local low-concurrency run, cgroup current memory totaled **644,546,560 bytes** and the sum of per-container lifetime peaks **817,999,872 bytes**. Peaks are independent high-water marks, not simultaneous whole-host memory, and Docker Desktop's VM/cache/other projects are excluded. CPU caps can contend on a two-core host. Recommended **one x86_64 Linux host, 2 vCPU, 4 GiB, 80 GiB SSD**, prebuilt images only, small gated demo traffic; no GPU. A 2 GiB host is below configured container ceilings and is not recommended. Choose 8 GiB/4 vCPU for larger concurrency or uncertain traffic; remeasure on the selected host.
